## Highlights

- **Modular Monolith Core Architecture:** Extracted `app/core/` infrastructure (`config.py`, `extensions.py`, `logging.py`, `security.py`, `errors.py`, `responses.py`), slimmed application factory root, and enforced import boundaries via static tests.
- **Provider-Neutral AI Infrastructure:** Central AI gateway (`app/ai/gateway.py`), task-based model routing (`app/ai/routing.py`), prompt registry with configuration rollback, and non-sensitive usage/cost telemetry (`AIUsageRecord`).
- **Durable Background Job Queue:** Database-backed queue with atomic claims, renewable leases, exponential backoff retries, dead-letter state, and dedicated worker/scheduler processes.
- **Execution Profiles & Hardened Sandbox:** 5 server-selected execution profiles (`browser_python`, `container_python`, `container_data_science`, `container_ml`, `gpu_training`), resource-limited container execution (`sandbox/runner.py`), and durable project artifact storage (`app/services/artifacts.py`).
- **Traceable Project Studio Evidence:** Append-only `ProjectEvaluation` model rejecting single scores; multi-source evidence combining automated checks, rubric criterion feedback, evidence references, and privileged human review; two-key competency linkage; and public portfolio whitelist.
- **Production Operations & Observability:** JSON request observability, correlation IDs (`X-Request-ID`), bounded SQL/latency metrics, generic service heartbeats (`ServiceHeartbeat`), admin operations snapshot, scheduler daemon, and database backup/restore automation scripts.
- **Reconciled Migration Graph:** Unified single migration head `m7n8o9p1q2r3` with zero drift (`flask db check` reports no new upgrade operations).
- **Release Hygiene:** Fail-closed source distribution exporter (`scripts/export_release_source.sh`) with SHA-256 checksums, manifest validation, and automated CI secret scanning.
